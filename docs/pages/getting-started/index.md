# Welcome to VISR

VISR is an experimental runtime for interfaces that can move across spatial environments and adapt to the capabilities available there. The project combines a declarative interface language, an application contract, a runtime, rendering backends, and XR device boundaries.

This site describes the direction and the implementation as it exists today. It is an evolving project, not a finished product specification.

## Project status

VISR is under active development. Some boundaries are implemented in the C++ codebase; others remain exploratory. Pages call out that distinction where it matters.
