# Hardware and capabilities

VISR aims to keep device-specific implementations behind portable boundaries. The current code includes view, tracking, and presentation contracts, an OpenXR implementation, and a simulator for development. This is an architectural direction, not a claim of broad device support.

Future hardware documentation can grow around these subjects:

- Displays and per-view metrics.
- Tracking, poses, joints, and events.
- Input devices and interaction.
- Audio and cameras.
- Spatial awareness and environment sensing.
- Optional capabilities, discovery, and fallback behavior.

Most of these topics do not yet have a complete implementation or specification in VISR.
