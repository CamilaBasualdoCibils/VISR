# Applications

The Application layer describes the contract between an app and the VISR environment. In the current source, applications register state, actions, metadata, and optional templates; they do not own environment windows or visual surfaces.

The runtime consumes that contract to resolve interface documents and present a live experience. Scripting adapts scripts to the same application model rather than creating a separate presentation path.

This page is an orientation point. Detailed authoring guidance will follow as the application API and packaging model settle.
