# Goals

These are design goals that guide exploration, not promises that every capability is complete today.

## Hardware independence

Keep portable contracts separate from concrete display, tracking, graphics, and operating-system implementations.

## Capability-driven experiences

Let an experience make use of available capabilities without assuming every environment has the same devices.

## Spatial computing

Treat spatial context as a first-class direction for interfaces, while keeping ordinary displays and development simulators useful.

## Graceful degradation

Make it possible for an experience to remain useful when optional capabilities are absent. The exact fallback model is still being explored.

## Application portability

Give applications a stable contract with the environment instead of requiring them to own the window, surface, or device integration.

## Extensibility

Allow new capabilities and implementations to fit behind explicit boundaries as the project grows.
